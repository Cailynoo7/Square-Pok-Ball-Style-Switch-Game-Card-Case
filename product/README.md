# 精灵球配色 Switch 游戏卡收纳盒

## 产品
桌面正立方体收纳盒，2列、每列7槽，等间距收纳14张Switch游戏卡。红色上半和白色下半等高，黑色腰线居中，正面灰色圆形按钮按压解锁，红盖沿背面铰链向上翻开。

## 内部结构
上下黑色内胆分别与外露黑边及卡槽一体。每张卡竖放，下盒保留2列×7个独立槽；下方两列卡槽整体后移，上内胆每列一个完整直壁长腔，共两个；取消弧形退让，保留原露卡高度，合计14张。黑胆隐藏外缘内缩，红白外壳各保留2.4mm壁厚。外壳为有侧壁的结构杯，胶合定位在内胆外，不是薄装饰贴片。纯机械产品，无电路或布线。

## 尺寸与默认项
主体外包络68×68×68mm，圆角并不改变三向等长。白色下外壳底边与红色上外壳顶边采用更大的对称圆角，默认半径6.0mm；内侧圆角随外侧调整，保留2.4mm主体壁厚。红白壳可见高度各30mm，中间黑边总高8mm，上下黑色内胆合缝0.3mm，两侧对称各收紧0.05mm。红白外壳略微凸出外露黑色内胆，默认腰线向内退0.8mm。黑色下内胆的前圆座正面与黑色前沿齐平，白色按钮环正面与白色外壳前面齐平。灰按钮减薄并降低外凸，默认直径13mm、面帽厚1.6mm、向外突出白壳前面1.0mm。独立白环外径19mm、内径13.6mm、环带宽2.7mm、厚1.2mm，嵌入黑色圆座0.4mm深、直径19.4mm的定位浅槽。灰按钮与白环保持当前小尺寸，外露黑环再略收窄：黑圆座外径默认24mm，白环外缘至黑圆座外缘的径向露出宽度约2.5mm；红白壳的半圆缺口同步缩小，径向留0.5mm间隙。
卡片研究标称约31×21×3mm；没有取得任天堂公差图，因此采用31.2×21.2×3.3mm保守设计包络。槽直段21.8×3.8mm，纵向节距6.4mm，隔筋2.6mm。下盒槽底z=14mm，闭盒分界z=34mm；下段名义20mm，上盖提供11.6mm高度空间。下方两列7槽整体后移，默认后移1.5mm。上内胆左右各一个完整直壁长腔，无横向小隔筋和弧形退让；宽21.8mm，前缘保持y=-21.1mm，后缘配合下槽延长1.5mm至y=22.6mm，长43.7mm。下槽深度和露卡高度保持不变。推荐开盖0—100°。
宽度方向由2×21.8+4.2mm中央筋=47.8mm槽区，深度由7×3.8+6×2.6=42.2mm槽区，加内胆边壁、前锁舌区、后铰链区及外壳后，选择68mm等边主体。该尺寸是工程默认，可改。
默认FDM制造，黑色内胆及锁舌用PETG，红白外壳与白环默认PLA，灰按钮PETG，0.4mm喷嘴、0.2mm层高。灰按钮机械推压黑胆弹性锁舌，解锁后手动翻开，不包含自动弹盖。后轴默认用直径1.75mm耗材直段，无螺丝。

## 外部参考
外观以用户上传图片为准，但必须将红色部分加高至与白色等高，并修正为正立方体。
卡片标称尺寸研究： https://consolemods.org/wiki/Dimensions_for_Game_Cartridges （该表标注未确认），以及实测作者检索摘要 https://melburn119.tistory.com/m/1378 （正文获取超时）。这些不是制造商公差图；模型使用额外包络余量。

## 验收
主体三向等长；红白可见高度相等；下盒14槽为2×7等距布局；卡片闭合后不与上盖相交，开盖路径不夹卡；灰按钮的推动方向能够释放锁舌；红白壳最薄主体壁不小于2.4mm；每个打印零件为单一实体且能放入180×180×180mm普通打印机；最终检查装配干涉及开盖过程。

## 首件制造默认
先打印小件和完成无胶干装；空盒20次、满14卡10次开合为首件初筛。同批余料胶合后等待24小时检查粘结，通过后再胶合成品。这些是工程默认的首件检查，不是耐久认证。材料采购与备料量见[材料清单](materials.md)，实际试验结果在[首件试装清单](first-article-checklist.md)中填写。
