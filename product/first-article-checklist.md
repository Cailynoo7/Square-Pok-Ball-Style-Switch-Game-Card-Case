## 1. 先小件，再大件

- [ ] 打印锁舌3件、灰按钮2件、白环2件，检查细杆、挡边和环带完整，无层裂；用同批PETG/PLA支撑做余料胶合试验。
- [ ] 打印上下黑色内胆各1件，彻底移除轴孔、卡槽、扣梁和按钮导向里的支撑与毛刺。
- [ ] 打印红白外壳各1件，清理隐藏内腔，外侧大圆角不留支撑凸点。
- [ ] 不整体缩放任何零件；某处偏紧先排除毛刺、象脚、潮料和挤出偏差，再记录具体位置。

## 2. 无胶试装

- [ ] 灰按钮从黑色下胆内侧装入：直径13mm可自由移动，挡边留内侧，约1mm外凸可见；手按不刮白环、不歪斜。
- [ ] 将锁舌根部临时固定在定位座，长臂保持自由；可用窄纸胶带仅固定根部，不能覆盖受弯臂。按键约1.8mm行程能使锁钩退让，松手能返回。
- [ ] 用约60mm长的直PETG耗材轴穿过交错轴节；无须硬推，不在卡住时强掰。确认孔已清理，轴未弯曲。
- [ ] 不按键时盖子能扣住，按键后能手动打开；不承诺自动弹盖。
- [ ] 合盖后四边合缝约0.3mm且均匀，不磨擦、不被夹紧；实际测量：前____ 后____ 左____ 右____mm。以模型设计值为比较，不把它当成打印公差保证。
- [ ] 将红白壳与白环干装：黑圆座与黑前沿齐平、白环与白壳前面齐平；外壳不挤住按钮或铰链。
- [ ] 卡片先试1张：检查无支撑残留或锐毛刺，再轻插到底并取出，不用蛮力，不刮触点。
- [ ] 逐槽试完两列各7槽，再放满14张卡；闭合不压卡、打开不顶卡，卡片能逐张取出。

## 3. 动作初筛（工程默认，不是寿命认证）

- [ ] 空盒开合20次：每次按键解锁、手动开至约100°、再闭合；无卡滞、异响或反复对位。
- [ ] 满14卡开合10次：不碰卡、不带起卡片，不强掰超过推荐100°。
- [ ] 在软布上方将满卡闭锁的盒子倒置10秒：盖子不自行脱扣。不要进行抛掷或跌落试验。
- [ ] 检查锁舌根部与钩尖，无白化、裂纹、永久弯曲；否则换备件并记录，不用加大量胶硬补。
- [ ] 同批PLA/PETG余料胶合24小时后手掰：胶层已硬化，不轻易整片剥离；不通过则暂停成品胶合。

## 4. 最后胶合与复测

- [ ] 取出游戏卡、保持盖子打开，确认全部干装项目通过。
- [ ] 少量环氧胶只涂锁舌根部；不得碰长臂、钩尖、推杆或按钮导向。
- [ ] 将白/红壳各自胶合到对应内胆隐藏接触区；胶不得进入0.3mm合缝和后轴孔。
- [ ] 白环只胶合浅槽底部，正面与白壳齐平；不要把按钮粘在环里。
- [ ] 室温等待至少24小时，包装要求更长时按包装。混胶比例、温度和等待时间：________________。
- [ ] 铰链确认顺畅后，轴修至约54mm；仅处理外露端部限位，不熔死孔内轴。需要继续排查时先保留可拔轴。
- [ ] 再做空盒20次、满卡10次开合及软布上方倒置检查，按钮能回弹、盖子能闭锁、卡片能取出。
