# 立方体精灵球卡盒
桌面手持物件，玩具感、饱满、对称。外形为68×68×68mm圆角正立方体，红白可见高度各30mm，黑色腰线共8mm，上下内胆合缝收紧至0.3mm，上下各向合缝面增加0.05mm。参考用户配色图片，修正矮红盖比例。正面-y，背面+y；外露黑色腰线每侧内退0.8mm，红白壳略凸出；前方灰色按钮直径13mm、面帽厚1.6mm，白环（首件默认白PLA）外径19mm/内径13.6mm/环带宽2.7mm/厚1.2mm，嵌入黑色下内胆圆座0.4mm浅槽，白环正面与白色外壳前面齐平；黑色圆座正面与黑色前沿齐平。外侧黑圆座直径24mm，白环外露黑边径向宽约2.5mm，灰按钮外凸白壳1.0mm。前方灰色按钮中心z34，后侧隐藏铰链。红#ed202c，白#f0eee8，黑#17191c，按钮灰#969a9e。FDM分色制造。白色下壳底边和红色上壳顶边圆角对称放大至R6.0mm，内侧取R3.6mm，黑色内胆隐藏端部配合退让。

## 结构与接口
card_slots：下内胆2列×7个独立定位槽，宽21.8、厚3.8、节距6.4mm，列中心x±13。采用31.2×21.2×3.3mm保守卡片包络。槽底z14，下胆顶z33.85，下段深19.85mm；闭盒分界z34，卡片上露约11mm，上盖退让腔高11.6mm。
下方两列7槽整体向后移动1.5mm，节距和深度保持。上盖仅保留左右两个完整直壁长腔，每腔宽21.8、长43.7、深11.6mm；y范围[-21.1,22.6]。取消前缘弧形退让，前缘保持，后缘延长1.5mm容纳最后一排卡片。中央筋4.2mm，露卡约11mm。
hinge：轴线沿x、y31 z34，打印轴孔2.15，直径1.75耗材轴长54mm。推荐开合0—100°，不要强掰到超过后壳。
push_latch：灰按钮行程1.8mm，推PETG悬臂向内弯曲；锁钩退出上盖扣梁，随后手动上翻。没有自动弹盖弹簧。
shell_carrier：隐藏黑胆宽62.6，套装红白结构杯，杯壁2.4，径向胶层间隙0.3mm。红白杯各自有30mm侧壁，属于立体结构杯，并非薄平板装饰片。

## 连接清单
shell_carrier、hinge、push_latch、card_slots、white_ring均为free定制实现，说明见产品约束。无螺丝、无电子元件、无布线；不需要PCB。白环胶合在黑色下内胆前圆座上；attach_panel_v1(method=glue_pad)已对该接口拒绝：接触带太窄，不能放置隐藏连接特征。因此采用free平面环形少量胶合，胶不得进入按钮孔。上下内胆分别为单一黑色实体，与各自腰线和卡槽一体。

## 几何验证
最终闭合装配2c7ac50：7件打印件均为单一实体，另有1根耗材轴；14卡包络为reference不打印。9个对象36对无实体干涉。
黑色圆座外径24mm，白环外径19mm，因此外露黑边名义径向宽2.5mm。红白外壳半圆缺口及上内胆相应避让半径同步调整为12.5mm，保持0.5mm径向间隙。
灰按钮可见直径13mm、面帽厚1.6mm、外凸白壳1mm；白环外径19mm、内径13.6mm、环带宽2.7mm、厚1.2mm，尺寸及齐平关系保持。
满卡上盖和红壳绕后轴0—100°，相对于卡片、下内胆、白壳、灰按钮、白环和轴无接触或干涉；网格公差0.02mm，最大采样步距0.15mm。沿路径卡片最小间隙0.25mm、下内胆0.30mm、轴约0.20mm、白环2.40mm。
黑色合缝0.3mm、彩壳R6外圆角、2.4mm主体壁厚、两列下槽后移1.5mm及上盖两列直壁长腔保持。
几何检查通过，可用于首件打印试装；锁扣按压力、回弹和寿命仍需实物确认。

## Making and assembly
0.4mm喷嘴、0.2mm层高。上下黑胆、弹性锁舌及灰按钮使用PETG；首件红白结构杯和白环统一用PLA。黑胆3—4圈壁，锁舌实心打印。
大圆角红白壳建议杯口朝下、封闭外观面朝上，内部放置支撑并用裙边或brim保证壳口附着，避免外侧R6曲面留下支撑痕。上黑胆翻转后打印，隐藏侧必要时支撑；下黑胆以底面朝床，底部减重腔的隐藏桥接面需支撑。支撑不得残留在卡槽、轴孔及按钮导向面。
锁舌侧放，使长臂轮廓在XY平面，根部和锁钩过渡不断层；不使用PLA锁舌。灰按钮可按前面朝床打印，支撑只在隐藏挡边。耗材轴不用打印，切取现有直径1.75mm直段54mm即可。
先干装按钮和锁舌，确认按压回弹；再插入耗材轴，检验上盖开合；再用14张卡试装；全部通过后才用少量适用PETG/PLA的环氧胶固定红白外壳和锁舌根部。禁止胶进入弹性臂、按钮间隙和轴孔。耗材轴端轻微熔头限位，不能熔死铰链。
尚无实物首件：卡片制造公差、打印机误差、按压力、回弹和长期耐久需试装验证。按当前标准槽尺寸先试印或试插，卡片有阻力时不要硬压。

白环背面平放打印，正面朝上；按钮装好、确认运动顺畅后再从正面套上白环，白环放入黑色圆座的0.4mm环形浅槽，正面与白壳前面齐平；少量胶仅涂定位浅槽底部的接触环带。白环不得粘到灰色按钮上。


## 材料与首件清单
材料选型、备料克数和每件打印数量见产品材料清单；实物验收见产品首件试装清单。默认备料黑PETG 250g、灰PETG 10g、白PLA 80g、红PLA 80g；已有余料或委托打印时不必买整卷。
胶水默认ZAP Z-Poxy 5 Minute，PT-36 1 oz注射器装1支，按体积1:1混合。用同批PLA/PETG余料先试粘并等待24小时，包装要求更久时从其规定。5分钟不作为完整固化时间。
先打印小件备份，完整干装并完成空盒20次、满卡10次开合，再胶合成品；固化后复测。物理结果尚未产生，清单勾选项保留空白。
